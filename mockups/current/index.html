story-writer, as it is

Every screen below is the running viewer, frozen: the app's own DOM with viewer.css inlined and the scripts dropped. Nothing is redrawn by hand, so what you see is what the app renders today — the baseline a redesign argues against. Interactions are dead; a few screens ship a -dark.html twin. Every screen is also a flat image in png/, same name, for anywhere HTML will not go.

Retake them all with npm run capture.
